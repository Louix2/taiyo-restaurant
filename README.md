# Taiyō Restaurant Website

*Built: 2024*

A fictional multi-page website for a made-up Japanese restaurant called "Taiyō", built as a school project. The goal was to practice HTML, CSS and a bit of JavaScript by building a small, realistic-looking business website (menu, drinks, events, reservation form, imprint).

**[View it live](https://louix2.github.io/taiyo-restaurant/)**

## Pages

- **Home** – opening hours and short teasers linking to the Christmas event and the drinks menu
- **Speisekarte (Menu)** – breakfast, lunch, dinner and to-go items
- **Getränkekarte (Drinks)** – non-alcoholic and alcoholic drinks
- **Events** – four seasonal events (Christmas, Hanami, Tsukimi, Shōgatsu) with themed menus
- **Spezials** – cooking classes, a sake evening, happy hour
- **Reservierung (Reservation)** – a form with basic JavaScript validation and a simulated confirmation
- **Impressum** – legally required imprint page (placeholder data, since the restaurant is fictional)

## Tech Stack

- HTML
- CSS (Grid layout, media queries for responsiveness)
- JavaScript (form validation, no backend/server involved)

## Running it

No installation needed — just open `index.html` in your browser, or use the live link above.
